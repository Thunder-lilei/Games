# 1-3 Z-Buffer + 多三角形叠加

**文件位置：** `1-3_zbuffer.py`

**目标：** 添加深度缓冲（Z-Buffer），处理三角形的前后遮挡关系。

## 核心概念

**Z-Buffer 原理：**
- 创建与 framebuffer 同尺寸的 depth_buffer，初始值设为正无穷（或一个很大的数）
- 对三角形内每个像素，通过**重心坐标**插值得到深度值 z
- 如果当前深度 `z < depth_buffer[y][x]`，则更新颜色**和**深度值
- 否则跳过（被遮挡）

**重心坐标：** 见 [核心概念.md](../核心概念.md)

## 实现步骤

1. **定义两个三角形**
   - 三角形 1（大红色，Z = 0.0）：
     - p0 = (100, 100, 0.0)
     - p1 = (400, 50, 0.0)
     - p2 = (200, 400, 0.0)
   - 三角形 2（蓝色，Z = 0.5）：
     - p0 = (50, 50, 0.5)
     - p1 = (450, 80, 0.5)
     - p2 = (250, 350, 0.5)
   - 顶点坐标多了一个 Z 分量，`z_A, z_B, z_C` 即顶点坐标的第三个值

2. **创建 depth_buffer**
   - `depth_buffer = [[float('inf')] * WIDTH for _ in range(HEIGHT)]`

3. **对每个三角形：**
   - 计算包围盒（只看 x, y，只检查包围盒内像素而非整张图片）
   - 遍历包围盒内每个像素
   - 计算 edge 值，判断是否在三角形内
   - 如果在三角形内，计算重心坐标 `alpha, beta, gamma`
   - 插值深度：`z = alpha * z_A + beta * z_B + gamma * z_C`
   - **深度测试：** 如果 `z < depth_buffer[y][x]`，则：
     - 更新 `depth_buffer[y][x] = z`（后续三角形的像素将与这个新值比较）
     - 更新 `framebuffer[y][x]` 为当前三角形的颜色
   - 否则跳过（像素被遮挡）

4. **输出到 PPM**
   - 文件路径：`output_1-3.ppm`
   - 格式与 1-1 相同

## 验收标准
- [ ] depth_buffer 初始值为 `inf`
- [ ] 深度判断正确，近处三角形遮挡远处
- [ ] 互换 z 值后遮挡关系正确反转
