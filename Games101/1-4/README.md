# 1-4 纹理映射

**文件位置：** `1-4_texture.py`

**目标：** 生成或加载一张纹理图，映射到三角形上。

## 核心概念

**UV 坐标：** 每个顶点附加一个 UV 坐标 `(u, v)`，范围 [0, 1]。通过重心坐标插值到三角形内每个像素，然后用插值后的 `(u, v)` 在纹理图上采样颜色。

**最近邻采样：**
```
tex_x = int(u * (tex_width - 1))
tex_y = int(v * (tex_height - 1))
color = texture[tex_y][tex_x]
```

UV 范围是 [0, 1]，纹理像素列号是 [0, tex_width-1]，所以乘 tex_width-1（而非 tex_width）避免 u=1 越界。注意采样时翻转 v：`v = 1.0 - v`。

## 实现步骤

1. **棋盘纹理文件** — `checkerboard.ppm` 已在目录中
2. **解析 PPM** — 跳过前三行（P3、宽高、255），后续每行三个数字为一个像素的 R G B
3. **定义带 UV 的三角形**
   - p0 = (150, 50, UV=(0.0, 0.0))
   - p1 = (50, 400, UV=(1.0, 0.0))
   - p2 = (450, 350, UV=(1.0, 1.0))
4. **渲染循环**
   - 包围盒遍历
   - 叉积判断内外
   - 重心坐标插值 UV
   - 翻转 v → 最近邻采样 → 写入 framebuffer
5. **输出 PPM** — `output_1-4.ppm`

- [ ] 三角形内纹理映射无接缝
