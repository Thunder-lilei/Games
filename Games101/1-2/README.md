# 1-2 画一个三角形

**文件位置：** `1-2_draw_triangle.py`

**目标：** 将三角形内的像素着色，输出为 PPM 图片。

---

## 核心概念

**包围盒（Bounding Box）：** 三角形在屏幕上的最小矩形区域，取三个顶点 x 的最小/最大值、y 的最小/最大值。
   - 只遍历包围盒内的像素，而不是整张图片（512×512=262,144 像素 → 仅需检查几百到几千像素，大幅减少无用计算）

**叉积判断法（Edge Function）：**
给定三角形三个顶点 `A, B, C`（逆时针顺序），对任意点 `P`：

```
edge(P, A, B) = (P.x - A.x) * (B.y - A.y) - (P.y - A.y) * (B.x - A.x)
edge(P, B, C) = (P.x - B.x) * (C.y - B.y) - (P.y - B.y) * (C.x - B.x)
edge(P, C, A) = (P.x - C.x) * (A.y - C.y) - (P.y - C.y) * (A.x - C.x)
```

如果三个 `edge` 值都 >= 0，则 `P` 在三角形内（含边界）。如果任意一个 < 0，则在三角形外。

## 实现步骤

1. **定义三角形顶点**
   - 三个顶点（屏幕坐标）：
     - `p0 = (200, 50)`
     - `p1 = (50, 400)`
     - `p2 = (450, 350)`

2. **计算包围盒**
   - `xmin = floor(min(p0.x, p1.x, p2.x))`
   - `xmax = ceil(max(p0.x, p1.x, p2.x))`
   - `ymin = floor(min(p0.y, p1.y, p2.y))`
   - `ymax = ceil(max(p0.y, p1.y, p2.y))`
   - 限制到 [0, WIDTH-1] 和 [0, HEIGHT-1] 范围内

3. **遍历包围盒内每个像素**
   - 对每个像素 `(px, py)`：
     - 取像素中心点 `(px + 0.5, py + 0.5)`
     - 用叉积公式计算三个 `edge` 值
     - 如果三个值都 >= 0，则像素在三角形内，着色为红色 `[255, 0, 0]`
     - 否则保持黑色 `[0, 0, 0]`

4. **输出到 PPM**
   - 文件路径：`output_1-2.ppm`
   - 创建或清空 framebuffer（形状 `(HEIGHT, WIDTH, 3)`，初始全黑）
   - 将三角形内的像素在 framebuffer 中设为红 `[255, 0, 0]`
   - 写入 PPM 文件：
     - 第一行：`P3`
     - 第二行：`WIDTH HEIGHT`
     - 第三行：`255`
     - 之后逐行逐像素写入 `framebuffer[y][x][0] framebuffer[y][x][1] framebuffer[y][x][2]`

## 验收标准
- [ ] 生成一个红色三角形，三个顶点分别在左上、左下、右下方向
- [ ] 三角形边缘干净，内部无空洞
- [ ] 三角形外部为黑色
