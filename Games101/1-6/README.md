# 1-6 组合：渲染一个彩色立方体

**文件位置：** `1-6_cube.py`

**目标：** 综合前面所有知识（三角形光栅化、Z-Buffer、MVP 变换），渲染一个 3D 彩色立方体。

## 预备知识

**MVP 变换：** 把 3D 物体"拍扁"到屏幕上的过程。

| 步骤 | 人话 | 效果 |
|------|------|------|
| **Model** | 拿着立方体转一转 | 先绕 X 轴转 -15°，再绕 Y 轴转 20° |
| **View** | 把相机架到右前方，对准立方体 | 从 (1,1,1) 看过去 |
| **Projection** | 按下快门，**远处的变小近处的变大** | 产生透视效果 |
| **透视除法** | 把坐标标准化到 [-1,1] 方盒子里 | 与屏幕分辨率无关 |
| **视口变换** | 把标准底片拉伸到 512×512 像素 | 填满画布 |

变换顺序：`Projection × View × Model × vertex`（顶点右乘）

**齐次坐标：** `(x, y, z, 1.0)` → 4×4 矩阵统一变换 → 透视除法 `(x/w, y/w, z/w)` 回到 3D。

## 立方体定义

8 个顶点，每条边 1 单位长度，中心在原点：

```
A = (-0.5, -0.5,  0.5)     B = ( 0.5, -0.5,  0.5)
C = (-0.5,  0.5,  0.5)     D = ( 0.5,  0.5,  0.5)
E = (-0.5, -0.5, -0.5)     F = ( 0.5, -0.5, -0.5)
G = (-0.5,  0.5, -0.5)     H = ( 0.5,  0.5, -0.5)
```

每个面由两个三角形构成，各面颜色和法线：

| 面 | 顶点 | 颜色 | 法线 |
|----|------|------|------|
| 前面 Z+ | A→B→C, B→D→C | 蓝 | (0,0,1) |
| 右面 X+ | B→F→D, F→H→D | 红 | (1,0,0) |
| 后面 Z- | F→E→H, E→G→H | 绿 | (0,0,-1) |
| 左面 X- | E→A→G, A→C→G | 黄 | (-1,0,0) |
| 顶面 Y+ | C→D→G, D→H→G | 紫 | (0,1,0) |
| 底面 Y- | A→E→B, E→F→B | 橙 | (0,-1,0) |

## 核心概念

**Z-Buffer：** 每个像素存当前最近物体的深度，新像素只有深度更近（z 更小）才覆盖，解决遮挡关系。

**包围盒优化：** 只遍历三角形在屏幕上的最小矩形区域，减少无用像素判断。

**重心坐标插值深度：** 用面积比算出像素离三个顶点的权重，插值出该像素的深度值用于 Z-Buffer 测试。

## 实现步骤

1. 实现 4×4 矩阵乘法和向量运算函数
2. 实现 MVP 矩阵构建（Model/View/Projection/Viewport）
3. 定义立方体 8 个顶点和 12 个三角形
4. 对每个三角形：MVP 变换顶点 → 包围盒 → 重心坐标判断内部像素 → Z-Buffer 测试 → 写入颜色
5. 输出 PPM

- [ ] 面之间有正确的遮挡关系（Z-Buffer 工作正常）
- [ ] 旋转角度可调
