### 1-3 Z-Buffer + 多三角形叠加

**文件位置：** `./1-3_zbuffer.py`

**目标：** 添加深度缓冲（Z-Buffer），处理三角形的前后遮挡关系。

#### 核心概念

**Z-Buffer 原理：**
- 创建与 framebuffer 同尺寸的 depth_buffer，初始值设为正无穷（或一个很大的数）
- 对三角形内每个像素，通过**重心坐标**插值得到深度值 z
- 如果当前深度 `z < depth_buffer[y][x]`，则更新颜色**和**深度值
- 否则跳过（被遮挡）

**重心坐标：**
对三角形 `(A, B, C)` 内的点 `P`，可以表示为：

```
P = α*A + β*B + γ*C
α + β + γ = 1
```

其中 `α, β, γ` 是重心坐标。用之前算的三个 `edge` 值计算：

```
alpha = edge(P, B, C) / edge(A, B, C)
beta  = edge(P, C, A) / edge(A, B, C)
gamma = edge(P, A, B) / edge(A, B, C)
```

注意分母 `edge(A, B, C)` 的值等于 `2 × 三角形面积`。三个分子 `edge(P, B, C) + edge(P, C, A) + edge(P, A, B) == edge(A, B, C)`，所以 `alpha + beta + gamma = 1` 恒成立。

有了重心坐标，可以插值任何顶点属性：
```
value = alpha * val_A + beta * val_B + gamma * val_C
```

#### 实现步骤

1. **定义两个三角形**
   - 三角形 1（大红色，Z = 0.0）：
     - p0 = (100, 100, 0.0)
     - p1 = (400, 50, 0.0)
     - p2 = (200, 400, 0.0)
   - 三角形 2（蓝色，Z = 0.5）：
     - p0 = (50, 50, 0.5)
     - p1 = (450, 80, 0.5)
     - p2 = (250, 350, 0.5)
   - 注意：这里顶点坐标多了一个 Z 分量

2. **创建 depth_buffer**
   - `depth_buffer = [[float('inf')] * WIDTH for _ in range(HEIGHT)]`
   - 或者用 numpy：`depth_buffer = np.full((HEIGHT, WIDTH), float('inf'))`

3. **对每个三角形：**
   - 计算包围盒（只看 x, y）
   - 遍历包围盒内每个像素
   - 计算 edge 值，判断是否在三角形内
   - 如果在三角形内，计算重心坐标 `alpha, beta, gamma`
   - 插值深度：`z = alpha * z_A + beta * z_B + gamma * z_C`
   - 如果 `z < depth_buffer[y][x]`：
     - `framebuffer[y][x] = 颜色`
     - `depth_buffer[y][x] = z`
   - 否则跳过

4. **输出 PPM**

#### 测试思路
- 两个三角形不重叠 → 两个都完整显示
- 两个三角形 z 不同且有重叠部分 → 近的遮挡远的
- 互换两个三角形的 z 值 → 遮挡关系反转

#### 验收标准
- [ ] depth_buffer 初始值为 `inf`
- [ ] 深度判断正确，近处三角形遮挡远处
- [ ] 互换 z 值后遮挡关系正确反转

### 1-4 纹理映射

**文件位置：** `./1-4_texture.py`

**目标：** 生成或加载一张纹理图，映射到三角形上。

#### 核心概念

**UV 坐标：** 每个顶点附加一个 UV 坐标 (u, v)，范围 [0, 1]。通过重心坐标插值到三角形内每个像素，然后用插值后的 (u, v) 在纹理图上采样颜色。

**最近邻采样：**
```
tex_x = int(u * (tex_width - 1))
tex_y = int(v * (tex_height - 1))
color = texture[tex_y][tex_x]
```

#### 实现步骤

1. **生成棋盘纹理**
   - 纹理尺寸：256×256
   - 用双层循环，对每个像素 `(tx, ty)`：
     - 判断所在格子：`cell_x = tx // 32`，`cell_y = ty // 32`
     - 如果 `(cell_x + cell_y) % 2 == 0` → 白色 [255, 255, 255]
     - 否则 → 红色 [200, 50, 50]

2. **定义带 UV 的三角形**
   - 三角形顶点（含 UV）：
     - p0 = (150, 50,  UV=(0.0, 0.0))
     - p1 = (50, 400, UV=(1.0, 0.0))
     - p2 = (450, 350, UV=(1.0, 1.0))

3. **渲染**
   - 遍历三角形包围盒
   - 叉积判断内外
   - 重心坐标插值 UV
   - 用 UV 采样纹理
   - 写入 framebuffer

4. **输出 PPM**
   - 输出：`output_1-4.ppm`

#### 纹理坐标验证
- 如果纹理正确映射，棋盘格应该随三角形透视而变形（近大远小效果）

#### 可选：从文件加载纹理
- 在网上找一张图片，下载到 `./` 目录，用在线工具（搜索 "image to ppm"）转为 PPM 格式
- 然后在 Python 中解析 PPM 文件头获取宽高，读取后面的 RGB 数据填充到纹理数组
- PPM 解析方式：跳过前三行（P3、宽高、255），后续每三个数字为一个像素的 R G B

#### 验收标准
- [ ] 棋盘纹理正确生成
- [ ] 三角形内纹理映射无接缝
- [ ] UV 插值正确，纹理方向正确

### 1-5 Blinn-Phong 着色

**文件位置：** `./1-5_blinn_phong.py`

**目标：** 给三角形添加光照计算，输出带有立体感的渲染结果。

#### 核心概念

**Blinn-Phong 模型公式：**

```
L = L_ambient + L_diffuse + L_specular
```

其中：
- `L_ambient = ka * Ia`（环境光，与位置无关）
- `L_diffuse = kd * I * max(0, n·l)`（漫反射）
- `L_specular = ks * I * max(0, n·h)^p`（高光）
  - `h = normalize(l + v)`（半程向量）
  - `p` 是高光指数（Phong exponent），值越大高光点越小越亮

符号说明：
- `ka, kd, ks`：环境色、漫反射色、高光色（RGB 向量）
- `Ia`：环境光强度
- `I`：光源强度
- `n`：表面法线（单位向量）
- `l`：光线方向（从交点指向光源，单位向量）
- `v`：视线方向（从交点指向摄像机，单位向量）

#### 实现步骤

1. **添加光照参数**
   ```python
   light_pos = (200, 100, 100)   # 光源位置
   light_intensity = 1.5         # 光源强度
   ka = [0.1, 0.1, 0.1]          # 环境光颜色（暗灰色）
   kd = [1.0, 0.0, 0.0]          # 漫反射色（红色物体）
   ks = [1.0, 1.0, 1.0]          # 高光色（白色）
   p = 32                         # 高光指数
   ```

2. **三角形顶点增加法线**
   - 三角形顶点格式：`(x, y, z, nx, ny, nz)`
   - 法线通过重心坐标插值到每个像素，然后归一化

3. **对每个像素计算光照**
   - 插值得到：三维空间位置 `P`、法线 `n`
   - 归一化法线：`n = normalize(n)`
   - 计算光线方向：`l = normalize(light_pos - P)`
   - 计算视线方向：`v = normalize(camera_pos - P)`
   - 计算半程向量：`h = normalize(l + v)`
   - 根据 Blinn-Phong 公式计算颜色
   - 将计算结果写入 framebuffer

4. **输出 PPM**

#### 提示
- 法线插值后**必须归一化**，否则光照计算错误
- 所有向量运算使用 `numpy` 或手写函数
- 颜色最终值在 [0, 255] 范围内取整

#### 验收标准
- [ ] 三角形表面有明暗过渡（非均匀颜色）
- [ ] 高光点位置随光源移动而变化
- [ ] 环境光保证了背光面也不是纯黑

### 1-6 组合：渲染一个彩色立方体的线框+面

**文件位置：** `./1-6_cube.py`

**目标：** 综合前面所有知识，渲染一个 3D 立方体。

#### 实现步骤

1. **定义立方体**
   - 8 个顶点，每条边 1 单位长度，中心在原点
   - 顶点坐标：
     ```
     (-0.5, -0.5, -0.5)  →  ( 0.5, -0.5, -0.5)
     (-0.5,  0.5, -0.5)  →  ( 0.5,  0.5, -0.5)
     (-0.5, -0.5,  0.5)  →  ( 0.5, -0.5,  0.5)
     (-0.5,  0.5,  0.5)  →  ( 0.5,  0.5,  0.5)
     ```
   - 12 个三角形（6 个面，每面 2 个三角形）

2. **MVP 变换（手写 4×4 矩阵乘法）**

   所有顶点从三维坐标转为齐次坐标 `(x, y, z, 1.0)`，依次乘以三个矩阵：

   **Model 矩阵：绕 Y 轴旋转 30°（角度需转为弧度）**
   ```
   [ cos(θ)  0  sin(θ)  0 ]
   [    0    1    0     0 ]
   [ -sin(θ) 0  cos(θ)  0 ]
   [    0    0    0     1 ]
   ```

   **View 矩阵：摄像机在 (1, 1, 1) 看向原点，up 方向为 (0, 1, 0)**
   - 先计算三个基向量：`g = normalize(看向的点 - 摄像机位置) = normalize(-cam_pos)`，`t = up`，`g × t` 为右向量
   - 拼出 4×4 View 矩阵

   **Projection 矩阵：透视投影**
   ```
   FOV = 45°（转为弧度），aspect = 1，n = 0.1，f = 10
   t = n * tan(FOV/2)
   r = t * aspect
   
   [ n/r    0      0          0     ]
   [  0    n/t     0          0     ]
   [  0     0   (n+f)/(n-f)  2nf/(n-f)]
   [  0     0      -1         0     ]
   ```

   变换顺序：`projection × view × model × vertex`（注意矩阵乘法的顺序，顶点在右侧）

   **透视除法：** 将变换后的 `(x, y, z, w)` 的 x、y、z 分别除以 w，得到 NDC 坐标 [-1, 1]

   **视口变换：** NDC → 屏幕坐标
   ```
   screen_x = (ndc_x + 1.0) * 0.5 * WIDTH
   screen_y = (1.0 - ndc_y) * 0.5 * HEIGHT   （y 翻转，因为屏幕 y 向下）
   ```

3. **渲染**
   - 使用 Z-Buffer
   - 每个三角形独立渲染，每个顶点先变换到屏幕坐标
   - 对三角形面用 Blinn-Phong 着色

4. **输出 PPM**

#### 验收标准
- [ ] 看到立方体的三个面（正面、顶面、右侧面）
- [ ] 面之间有正确的遮挡关系
- [ ] 旋转角度可调

### 2-1 贝塞尔曲线

**文件位置：** `./2-1_bezier.py`

**目标：** 用 De Casteljau 算法绘制贝塞尔曲线。

#### De Casteljau 算法

给定控制点 `P0, P1, P2, ..., Pn` 和参数 `t ∈ [0, 1]`：

```
递归公式：
  Pi(k)(t) = (1-t) * Pi(k-1)(t) + t * P(i+1)(k-1)(t)
  其中 k = 1, 2, ..., n，i = 0, 1, ..., n-k
  初始值 Pi(0)(t) = Pi
最终结果为 P0(n)(t)
```

翻译成循环：
```
输入：控制点数组 points，参数 t
输出：曲线上的点

临时数组 = points 的副本
当临时数组长度 > 1：
  新数组 = []
  遍历 i=0 到 len(临时数组)-2：
    新点 = (1-t) * 临时数组[i] + t * 临时数组[i+1]
    新数组.append(新点)
  临时数组 = 新数组
返回 临时数组[0]
```

#### 实现步骤

1. **定义控制点**
   - 在屏幕坐标中定义 4 个控制点（创建 800×800 的画布）：
     - P0 = (100, 600)
     - P1 = (200, 100)
     - P2 = (600, 100)
     - P3 = (700, 500)

2. **绘制控制点**
   - 在控制点位置画一个小的实心圆或方块（半径 5 像素，红色）

3. **绘制连接线**
   - 用直线将控制点依次连接（灰色线，显示控制多边形）

4. **采样曲线**
   - `t` 从 0 到 1，步长 0.001
   - 对每个 `t`，用 De Casteljau 算法计算曲线上的点
   - 将这些点着色为白色

5. **输出 PPM**
   - 输出：`output_2-1.ppm`

#### 扩展
- 支持任意数量控制点（点击即可添加）
- 二次贝塞尔 vs 三次贝塞尔

#### 验收标准
- [ ] 曲线通过首尾控制点，不通过中间点但被吸引
- [ ] 控制多边形显示为灰色
- [ ] 改变控制点位置，曲线随之变化

### 3-1 光线与球体求交

**文件位置：** `./3-1_ray_sphere\`

#### 目录结构

```
3-1_ray_sphere/
├── CMakeLists.txt
├── main.cpp
├── vec3.hpp         # 向量类（手写）
└── ppm_writer.hpp   # PPM 写入工具
```

#### 光的表示

光线由原点和方向定义：
```
Ray(origin, direction)
P(t) = origin + t * direction,  t >= 0
```

#### 球体求交公式

球体方程：`|P - C|^2 = r^2`

代入光线方程求 t：
```
|origin + t * dir - C|^2 = r^2
```

展开为二次方程：
```
a = dot(dir, dir)
b = 2 * dot(origin - C, dir)
c = dot(origin - C, origin - C) - r^2

discriminant = b*b - 4*a*c
```

- `discriminant < 0`：无交点
- `discriminant >= 0`：两个交点
  - `t1 = (-b - sqrt(discriminant)) / (2*a)`
  - `t2 = (-b + sqrt(discriminant)) / (2*a)`
  - 取最小的正 t 值

#### 实现步骤

1. **手写 Vec3 类**
   - 成员：`x, y, z`
   - 运算符重载：`+, -, *, /, dot, cross, normalize, length`
   - 参考接口：
     - `Vec3::dot(a, b)` — 点积
     - `Vec3::cross(a, b)` — 叉积
     - `a.normalized()` — 返回单位向量
     - `a.length()` — 向量长度

2. **定义 Ray 结构体**
   - `Ray(Vec3 origin, Vec3 direction)`

3. **定义 Sphere 结构体**
   - `Sphere(Vec3 center, float radius, Vec3 color)`
   - 成员函数：`intersect(Ray ray, float& t)` — 返回是否相交，t 为交点距离

4. **主循环（光线生成）**
   - 创建 512×512 的 framebuffer
   - 摄像机在 `(0, 0, 3)`，看向原点
   - 对每个像素 `(x, y)`：
     - 将像素坐标映射到 NDC [-1, 1]：`ndc_x = (x + 0.5) / WIDTH * 2 - 1`，`ndc_y = (y + 0.5) / HEIGHT * 2 - 1`
     - 计算光线方向：`normalize(Vec3(ndc_x, ndc_y, -1))`（视点看向 -Z 方向）
     - 射线从 `camera_pos` 发出
   - 对每条光线遍历所有球体，找最近的交点
   - 如果有交点，计算法线 `n = normalize(P - sphere.center)`
   - 用简单的漫反射着色：`color = sphere.color * max(0, dot(n, light_dir))`

5. **CMakeLists.txt 内容**
   ```cmake
   cmake_minimum_required(VERSION 3.10)
   project(RaySphere)
   set(CMAKE_CXX_STANDARD 17)
   add_executable(ray_sphere main.cpp)
   ```

6. **构建与运行**
   ```
   cd 3-1_ray_sphere
   mkdir build && cd build
   cmake ..
   cmake --build .
   .\Debug\ray_sphere.exe
   ```

### 3-2 光线与三角形求交（Möller–Trumbore 算法）

**文件位置：** `./3-2_ray_triangle\`

**目标：** 用 MT 算法求光线与三角形的交点，渲染一个四面体或简单模型。

#### MT 算法公式

给定三角形顶点 `A, B, C` 和光线 `O + t*D`：

```
O + t*D = (1 - u - v)*A + u*B + v*C
```

整理为矩阵形式：

```
[-D,  B-A,  C-A] * [t, u, v]^T = O - A
```

用克莱姆法则求解：

```
E1 = B - A
E2 = C - A
S = O - A
S1 = cross(D, E2)
S2 = cross(S, E1)

t = dot(S2, E2) / dot(S1, E1)
u = dot(S1, S)  / dot(S1, E1)
v = dot(S2, D)  / dot(S1, E1)
```

交点条件：`t > 0, u >= 0, v >= 0, u + v <= 1`

#### 实现步骤

1. **定义 Triangle 结构体**
   - `Triangle(Vec3 v0, Vec3 v1, Vec3 v2, Vec3 color)`
   - 成员函数：`intersect(Ray ray, float& t, float& u, float& v)`

2. **定义一个四面体（4 个三角形）**
   - 四个顶点：`(0, 0.5, 0), (-0.5, -0.5, 0.5), (0.5, -0.5, 0.5), (0, -0.5, -0.5)`
   - 四个三角形面，每个面不同颜色

3. **主循环**
   - 与 3-1 相同的光线生成逻辑
   - 对每条光线，遍历所有三角形，用 MT 算法求交
   - 记录最近的交点
   - 如果有交点，用重心坐标插值法线，进行 Blinn-Phong 着色

4. **深度测试**
   - 由于是逐像素发光线，每个像素取最近的交点即可，不需要 Z-Buffer

#### 验收标准
- [ ] 正确渲染四面体，能看到三个面
- [ ] 每个面颜色不同，有光照效果
- [ ] 没有穿孔或错误的三角形

### 3-3 BVH 加速结构

**文件位置：** `./3-3_bvh\`

**目标：** 构建 BVH（Bounding Volume Hierarchy）树，加速大量三角形/球体的求交。

#### 核心概念

**包围盒（AABB）：** 轴对齐包围盒，由 `min` 和 `max` 两个点定义。

**AABB 与光线求交：**
```
t_min = (box.min - ray.origin) / ray.direction   (逐分量)
t_max = (box.max - ray.origin) / ray.direction   (逐分量)
如果 t_min 的某个分量 > t_max 的对应分量，交换它们
t_enter = max(t_min.x, t_min.y, t_min.z)
t_exit  = min(t_max.x, t_max.y, t_max.z)
如果 t_enter < t_exit 且 t_exit > 0，则相交
```
注意：当 `ray.direction` 的某个分量为 0 时，除法结果为无穷。如果此时光线原点在该维度上位于 box 范围内，则该维度不限制交距；否则不相交。代码中可以用 `if (dir == 0) t = infinity` 处理。

#### BVH 构建步骤

1. **定义 BVHNode 结构体**
   ```
   struct BVHNode {
       AABB box;
       BVHNode* left;     // 左子节点
       BVHNode* right;    // 右子节点
       int first_prim;    // 第一个图元的索引
       int n_prims;       // 图元数量（=1 时是叶子节点）
   };
   ```

2. **构建算法**
   - 如果当前图元数组长度 <= 阈值（如 2）：创建叶子节点
   - 否则：
     - 计算所有图元包围盒中心的包围盒
     - 选择跨度最大的轴作为分割轴
     - 按该轴中心值排序
     - 中位数分割，递归构建左右子树

3. **遍历算法**
   - 从根节点开始
   - 如果光线不与当前节点的 AABB 相交，直接返回
   - 如果是叶子节点：遍历该节点内的所有图元，求交
   - 如果是内部节点：递归遍历左右子树

#### 实现步骤

1. **实现 AABB 类和求交函数**
2. **实现 BVHNode 类（构建+遍历）**
3. **创建一个包含多个球体/三角形的场景（10+ 物体）**
4. **用 BVH 加速渲染，对比无 BVH 的性能**

#### 性能对比
- 在控制台打印：无 BVH 的求交次数 vs 有 BVH 的求交次数
- 预期：BVH 能减少 90%+ 的求交次数

#### 验收标准
- [ ] BVH 构建正确，场景渲染无误
- [ ] BVH 版本比朴素遍历版本快（肉眼可见差异）
- [ ] 求交次数大幅减少

### 3-4 路径追踪（最终目标）

**文件位置：** `./3-4_path_tracing\`

**目标：** 实现蒙特卡洛路径追踪，渲染带有间接光照的场景。

#### 核心算法

```
path_trace(ray, depth):
  if depth > max_depth:
    return black
  
  对场景求交，得到交点 P、法线 n、材质
  
  在交点 P 处，在法线方向的半球面上随机采样一个方向 wi
  
  沿 wi 发射新的光线
  
  递归计算 radiance = path_trace(new_ray, depth + 1)
  
  返回 emitted + (albedo / pi) * radiance * dot(n, wi) / pdf(wi)
```

蒙特卡洛积分的基本思想：用大量随机采样来近似积分结果，采样越多，结果越接近真实值。

#### Russian Roulette（俄罗斯轮盘赌）

解决递归无限深度的问题：
- 每次递归前，以概率 `P` 决定继续追踪，概率 `1-P` 停止
- 继续追踪的结果乘以 `1/P` 以保持无偏

```
if random() > survival_prob:
  return emitted  # 停止追踪，只返回自发光
else:
  return emitted + (albedo/pi) * radiance * dot(n, wi) / (pdf(wi) * survival_prob)
```

#### 实现步骤

1. **定义材质**
   - 漫反射材质：`albedo`（反射率）+ `emitted`（自发光颜色，非光源为 0）
   - 理想镜面反射（扩展）：给定反射方向

2. **半球面均匀采样**
   - 在法线方向上的半球面内生成随机方向
   - 用球坐标：`theta = acos(sqrt(random())), phi = 2*pi*random()`
   - 转换为笛卡尔坐标

3. **单像素多采样**
   - 每个像素发射 N 条光线（N = 32~512）
   - 结果取平均，减少噪点

4. **主循环**
   ```
   for 每个像素 (x, y):
     color = (0, 0, 0)
     for sample = 1 to samples_per_pixel:
       ray = generate_ray(x, y)
       color += trace(ray, 0)
     framebuffer[y][x] = color / samples_per_pixel
   ```

5. **输出 PPM**

#### 场景建议
- 一个大的漫反射球体作为地面
- 两个小球体，一个红色、一个蓝色
- 一个面光源（自发光材质，如方形）
- 场景被包围在一个大房间内

#### 验收标准
- [ ] 正确渲染漫反射间接光照
- [ ] 阴影区域有来自周围物体的颜色反射（颜色溢出）
- [ ] 增加采样数（spp）后噪点减少
- [ ] 光源区域正确发光
- [ ] 运行较慢是正常的——这就是路径追踪
