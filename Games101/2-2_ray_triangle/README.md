# 2-2 光线与三角形求交（Möller–Trumbore 算法）

**文件位置：** `2-2_ray_triangle/`

**目标：** 用 Möller–Trumbore 算法求光线与三角形的交点，渲染一个带 Blinn-Phong 光照的四面体。

## 预备知识

**光线表示：** 与 2-1 相同，`P(t) = origin + t * direction, t >= 0`。

**重心坐标：** 三角形内任意点可表示为 `P = (1 - u - v)*v0 + u*v1 + v*v2`，其中 `u, v` 是两个重心权重，条件 `u >= 0, v >= 0, u + v <= 1` 表示点在三角形内。

**三角形是 3D 模型的基本组成单元：** 真实模型（OBJ 文件）全由三角形网格构成。掌握了三角形求交，后续的 BVH 加速和路径追踪才能渲染任意模型——这是比球体更通用的图元。

## 新知识点

| 概念 | 说明 |
|------|------|
| **Möller–Trumbore 算法** | 用克莱姆法则解 3×3 线性方程组，一次性求出交点距离 t 和重心坐标 u、v |
| **四面体定义** | 4 顶点 + 4 个三角形面，每个面不同颜色 |
| **旋转摆放** | 绕 X 轴旋转 90° 让顶点 A 朝向相机，使相机同时看到三个面 |
| **法线朝向校验** | 用"面中心指向质心"的方向修正法线，保证始终朝外 |
| **重心坐标插值法线** | 用 u、v 插值三顶点法线得到交点处法线（平面三角形中结果即面法线） |
| **Blinn-Phong 着色** | 环境光 + 漫反射 + 高光三部分相加 |
| **隐式深度测试** | 逐像素发光线，对多个交点取最小正 t 即为可见表面 |

## MT 算法公式

给定三角形顶点 `A, B, C` 和光线 `O + t*D`：

```
O + t*D = (1 - u - v)*A + u*B + v*C
```

整理为矩阵形式：

```
[-D,  B-A,  C-A] * [t, u, v]^T = O - A
```

设 `E1 = B-A`、`E2 = C-A`、`S = O-A`、`S1 = D×E2`、`S2 = S×E1`，用克莱姆法则求解：

```
t = (S2 · E2) / (S1 · E1)
u = (S1 · S)  / (S1 · E1)
v = (S2 · D)  / (S1 · E1)
```

交点条件：`t > 0, u >= 0, v >= 0, u + v <= 1`。当分母 `S1 · E1` 接近 0 时，光线与三角形平行，无交点。

## 实现要点

1. **Triangle 结构体**：三个顶点 + 三顶点法线 + 颜色，成员函数 `intersect(Ray ray, float& t, float& u, float& v)` 实现 MT 算法
2. **四面体**：四个顶点 `(0, 0.5, 0), (-0.5, -0.5, 0.5), (0.5, -0.5, 0.5), (0, -0.5, -0.5)`，四个三角形面各一种颜色；绕 X 轴旋转 90° 让顶点 A 朝向相机
3. **主循环**：像素坐标映射 NDC → 发射光线 → 遍历所有三角形用 MT 算法求交 → 记录最近交点（深度测试取最小正 t）→ 重心坐标插值法线 → Blinn-Phong 着色 → 写入 framebuffer
4. **输出 PPM**：用 `__FILE__` 定位输出路径，PPM 固定生成在 `2-2_ray_triangle/` 根目录

## 构建与运行

```cmd
cd 2-2_ray_triangle
cmake -B build
cmake --build build
.\build\Debug\ray_triangle.exe
```
