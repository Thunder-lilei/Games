# 核心概念

## 一、光栅化

把三维空间的几何形体显示在屏幕上。

---

## 二、叉积判断法（Edge Function）

**用途：** 判断一个点是否在三角形内部。

**思路：** 给定逆时针顺序的三角形顶点 `A → B → C`，对任意点 P，依次计算三条边的**有符号距离**：

```
edge(P, A, B) = (P.x - A.x) * (B.y - A.y) - (P.y - A.y) * (B.x - A.x)
edge(P, B, C) = (P.x - B.x) * (C.y - B.y) - (P.y - B.y) * (C.x - B.x)
edge(P, C, A) = (P.x - C.x) * (A.y - C.y) - (P.y - C.y) * (A.x - C.x)
```

**为什么叉积能判断内外？**

每条边的 `edge(P, A, B)` 计算的是向量 `AP` 和向量 `AB` 的**二维叉积的 z 分量**：

```
AP × AB = |AP||AB|sinθ
```

- 如果 P 在 AB 的左侧（数学坐标系中三角形内部侧），叉积结果 > 0
- 如果 P 在 AB 的右侧，叉积结果 < 0
- 如果 P 恰好在 AB 上，叉积结果 = 0

一个点在三角形内，当且仅当它在**三条边的同一侧**（逆时针顶点时为左侧）。所以：

> 在数学坐标系（y 向上）中，三个 edge 值都 **>= 0** → P 在三角形内；
> 任意一个 **< 0** → P 在三角形外。

**⚠️ 屏幕坐标注意：** 屏幕坐标 y 轴向下，叉积的左右侧与数学坐标相反。所以屏幕坐标下，逆时针三角形内部像素的 edge 值全部 **≤ 0**。实际编码时用 `<=` 判断。

## 三、重心坐标

**用途：** 用一个点离三个顶点的"远近"，来插值该点处任意属性（深度、颜色、法线、UV 等）。

### 直觉理解

重心坐标 `(α, β, γ)` 是三个**权重**，表示点 P 离三个顶点有多"近"：

- 权重越大 → 越靠近对应的顶点
- P 是 A、B、C 的加权平均：**P = α·A + β·B + γ·C**
- 三个权重之和为 1：**α + β + γ = 1**

极端情况：
- 如果 P = A，则 `(α, β, γ) = (1, 0, 0)`
- 如果 P 在边 BC 上，则 `α = 0`

### 怎么算？用面积比

把 P 和三个顶点分别连线，三角形被分成三个子三角形：

```
         A
        /|\
       / | \
      /  |  \
     /   |   \
    B----P----C
```

- **α** = 子三角形(P,B,C) 的面积 ÷ 整个三角形(A,B,C) 的面积 — P **对面**的那个
- **β** = 子三角形(P,C,A) 的面积 ÷ 整个三角形面积
- **γ** = 子三角形(P,A,B) 的面积 ÷ 整个三角形面积

因为 `edge(P, B, C)` 的值正好等于 `2 × 子三角形(P,B,C) 的有符号面积`，所以可以用之前算的 edge 值直接算：

```
alpha = edge(P, B, C) / edge(A, B, C)
beta  = edge(P, C, A) / edge(A, B, C)
gamma = edge(P, A, B) / edge(A, B, C)
```

三个子三角形面积之和等于原三角形面积，所以 `α + β + γ = 1` 恒成立。

### 用重心坐标插值

有了重心坐标，可以对任意顶点属性做**线性插值**：

```
value = α × val_A + β × val_B + γ × val_C
```

可插值的属性包括：

| 属性 | 用途 |
|------|------|
| 深度 z | Z-Buffer 深度测试 |
| 颜色 | Gouraud 着色（平滑颜色过渡） |
| UV 坐标 | 纹理映射 |
| 法线 | Phong 着色（逐像素光照） |

---

## 四、UV 坐标

**UV 坐标**是人为指定"纹理上的哪个位置对应三角形的哪个顶点"，属于顶点属性。

每个顶点附带一个 `(u, v)`，范围 [0, 1]：
- (0,0) = 纹理左上角， (1,0) = 纹理右上角
- (0,1) = 纹理左下角， (1,1) = 纹理右下角

三角形内部每个像素的 UV 通过重心坐标插值得到，再从纹理中采样颜色。

> UV 不是从包围盒算出来的。包围盒只知道三角形"投影到了屏幕上的哪个区域"，但不知道纹理内容怎么对应到三角形上。UV 的存在就是为了人为指定这个对应关系。

---

## 五、包围盒优化

**包围盒（Bounding Box）：** 三角形在屏幕上的最小矩形区域——取三个顶点 x 的最小/最大值、y 的最小/最大值。

只遍历包围盒内的像素，而不是整张图片（512×512=262,144 像素→几百到几千像素），大幅减少无用计算。

---

## 六、法线（Normal）

**法线**是垂直于表面的单位向量，表示表面在某个点的"朝向"。例如桌面朝上、墙面朝前。

法线是光照计算的基础——它决定了表面能接收到多少光线（漫反射）以及高光的位置。

---

## 七、Blinn-Phong 着色模型

**用途：** 计算一个像素在光照下最终应该显示什么颜色。

### 三个组成部分

Blinn-Phong 把光照拆成三个独立的部分，加起来就是最终颜色：

```
final_color = ambient + diffuse + specular
```

#### ① 环境光（Ambient）

模拟场景中来自四面八方的微弱光线，即使背光面也不是全黑。

```
ambient = ka × kd
```

- `ka`：环境光强度系数（如 0.1 表示取 10% 的物体颜色作为环境底色）
- `kd`：物体本身的漫反射颜色（即用 0-1 表示的 [R, G, B]）

#### ② 漫反射（Diffuse）

光线照到粗糙表面后均匀向四周反射。**表面越正对光源就越亮**，侧面则暗。

```
diffuse = kd × light_intensity × max(0, n·l)
```

- `n`：表面在该像素处的**法线**（单位向量）
- `l`：从表面指向光源的方向（单位向量）
- `n·l`：法线和光源方向的**点积**。越接近 1 说明越正对光源，接近 0 说明在侧面
- `max(0, ...)`：背对光源时结果为 0，不受光
- `light_intensity`：光源强度，越大越亮

#### ③ 高光（Specular）

模拟光滑表面的镜面反射，产生"高光点"。只有当视线方向接近反射方向时才能看到。

```
specular = ks × light_intensity × (n·h)^p
```

- `v`：从表面指向**视线**的方向（单位向量）
- `h`：**半程向量** = 光源方向和视线方向的中间方向
  - `h = normalize(l + v)`
  - Blinn-Phong 用半程向量代替了原始 Phong 模型中的反射光方向计算，效果相似但更简单
- `n·h`：法线与半程向量的点积，值越大说明视线越接近反射方向
- `p`：**高光指数**，控制高光点的大小
  - `p` 越大 → 高光点越小越亮（光滑表面，如金属、镜子）
  - `p` 越小 → 高光点越大越淡（粗糙表面，如塑料、木头）
- `ks`：高光颜色系数（通常为白色 `[1, 1, 1]`）

### 完整代码示例

```python
# 假设已有：法线 n_world，像素世界坐标 P，物体颜色 color
kd = [c / 255.0 for c in color]          # 漫反射色（0-255 → 0-1）

# 环境光
ambient = [ka[i] * kd[i] for i in range(3)]

# 漫反射
l_dir = normalize(light_pos - P)          # 表面 → 光源方向
ndotl = dot(n_world, l_dir)
diffuse = [0, 0, 0]
if ndotl > 0:
    diffuse = [kd[i] * light_intensity * ndotl for i in range(3)]

# 高光（Blinn-Phong）
v_dir = normalize(camera_pos - P)         # 表面 → 视线方向
h_vec = normalize(l_dir + v_dir)          # 半程向量
ndoth = dot(n_world, h_vec)
specular = [0, 0, 0]
if ndoth > 0:
    spec = ndoth ** p
    specular = [ks[i] * light_intensity * spec for i in range(3)]

# 合并
final_color = [ambient[i] + diffuse[i] + specular[i] for i in range(3)]
```

## 八、齐次坐标（Homogeneous Coordinates）

平移变换无法用 3×3 矩阵表达为**线性变换**，所以把三维向量 `(x, y, z)` 扩展到四维 `(x, y, z, w)`，用 4×4 矩阵统一处理平移、旋转、缩放。

```
3D 点     → (x, y, z, 1.0)
3D 向量   → (x, y, z, 0.0)    （w=0 表示方向，平移时不受影响）
齐次 → 3D：(x, y, z, w) → (x/w, y/w, z/w)     （透视除法）
```

## 八、MVP 变换

MVP 是把三维模型显示到屏幕上的三个矩阵变换步骤：

```
Model → View → Projection → Viewport
```

**Model 矩阵：** 物体从自身坐标系 → 世界坐标系（平移/旋转/缩放）。

**View 矩阵：** 世界坐标系 → 以摄像机为原点的坐标系。

**Projection 矩阵：** 视锥体映射到 NDC 立方体 `[-1, 1]³`，产生近大远小效果。

**NDC（Normalized Device Coordinates，归一化设备坐标）** 是透视投影后的坐标：
- 范围：`x ∈ [-1, 1]`、`y ∈ [-1, 1]`、`z ∈ [-1, 1]`
- `(-1, -1)` 对应屏幕左下角，`(1, 1)` 对应屏幕右上角
- 与屏幕尺寸无关（512×512 还是 1920×1080，NDC 都是 [-1, 1]）
- 视口变换把 NDC 映射到实际像素坐标

之所以有 NDC 这一步，是为了把不同分辨率、不同宽高比的屏幕统一到一个标准坐标系里——渲染器只需要输出 NDC，最终显示交给视口变换。

**变换顺序：** `clip_pos = Projection × View × Model × vertex`（右乘）

**视口变换：** NDC → 屏幕坐标
```
screen_x = (ndc_x + 1.0) * 0.5 * WIDTH
screen_y = (1.0 - ndc_y) * 0.5 * HEIGHT
```
